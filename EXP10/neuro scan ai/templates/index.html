How to Compile & Run the Code (Guide)

1

Install Dependencies

Open Windows PowerShell or Command Prompt in the project folder and run:

pip install -r requirements.txt
2

Run Web Application Dashboard

Start the Flask web server covering all stages in one frame:

python app.py

Then open your browser to: http://127.0.0.1:5050

3

Compile / Train Classifier via Terminal

Train and save the ML model with cross-validation metrics:

python train_cli.py --algo "SVM" --c 1.0
4

Evaluate Performance via Terminal

Compute Confusion Matrix, Accuracy, and Classification Report:

python evaluate_cli.py
5

Predict Single MRI Image

Run inference on any MRI scan file:

python predict_cli.py --image "static/samples/tumor_glioma_sample.png"
